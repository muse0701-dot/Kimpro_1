# 살롱 포커 클럽 — 프로젝트 기록

칩 전용(현금 가치 없음) 세로형 홀덤 웹앱. 단일 파일 `index.html`로 동작한다.

- 플레이 링크: https://claude.ai/artifact/JQ7REHbufrEAsroYsW9QC7
- 작업 브랜치: `ccr-3af34b47-6jcbfy`

## 방향
- 참고 앱: **포커브로스만** 참고한다 (탑 로드는 참고하지 않기로 함).
- 기능·화면 흐름은 최대한 맞추되, 캐릭터·그림·음악·로고는 전부 오리지널로 만든다.
- 웹앱을 먼저 완성 → 앱 포장(Capacitor) → 필요하면 유니티로 이전.

## 들어 있는 기능
- 게임: 9인 노리밋 홀덤 캐시, 싯앤고(시간제 블라인드, 리엔트리 1회), AOF(15BB 고정), 밤 팟, 런 잇 트와이스, 사이드 팟, 배드빗 잭팟
- 캐릭터 21명(실사풍 3D 초상화, 설정에서 일러스트로 전환 가능), 게임 중 교체
- 로비: 클럽 만들기·가입·공지, 입장방 카드(엠블럼·좌석 막대·평균 팟), 테이블 만들기, 출석 달력(칩+골드), 행운의 룰렛
- 테이블: 베팅 패널(칩 기둥, ½·⅔·팟), 미리 선택(폴드/콜 N/무조건 콜), 앤틱 시계 타임뱅크, 왼쪽 메뉴, 안내·규칙·족보, 핸드 다시 보기·디테일
- 프로필: 상대 통계(VPIP·PFR·승률·손익), 태그(성향 아이콘·메모·색 외곽선), 채팅 숨김
- 골드 아이템: 공격·응원·재미 이모티콘 던지기, 무료 이모티콘 30/일, 무료 타임뱅크 15/일
- 설정: 프로필·사운드(볼륨)·알림·게임·테이블 탭

## 파일
- `index.html` — 게임 전체(그림은 WebP로 내장)
- `assets/characters/*.webp` — 캐릭터 원본(1024px, 투명 배경)
- `assets/art/*.webp` — 방 엠블럼, J·Q·K 그림, 카드 뒷면 원본
- `tools/qa.js` — 자동 오류 테스트 (Playwright). 예: `node tools/qa.js '{"width":390,"height":844}' quick`
  - 게임 안의 `window.__salon.state()/store()`는 이 테스트용 읽기 전용 확인 장치다.

## 마지막 검증

- 칩 누수·마이너스 칩·차례 오류·멈춤·스크립트 오류·화면 넘침 모두 0건
