마담스 홀덤, 경쟁 앱 9종과 나란히 놓고 보기

PokerBros, ClubGG, PPPoker, GGPoker, WSOP, PokerStars, X-Poker, Upoker, Zynga Poker의 메뉴·옵션·그래픽을 조사해 마담스 홀덤과 비교했습니다. 빠져 있던 기능 중 효과가 큰 7가지는 이번에 게임에 넣었습니다.

조사 앱 9새로 넣은 기능 7새 설정 토글 5버전 1.4 → 1.5

조사 기준일 2026년 11월 17일. 클럽형 앱(PokerBros·PPPoker·X-Poker·Upoker)은 공식 도움말이 공개되지 않아 세부 UI 자료가 적습니다. 표의 “?”는 기능이 없다는 뜻이 아니라 출처로 확인하지 못했다는 뜻입니다.

한눈에 보는 결론

마담스 홀덤은 이미 클럽형 앱의 핵심을 대부분 갖췄습니다. 클럽·봄팟·런 잇 트와이스·사전 행동·타임뱅크·던지기·상대 태그·핸드 리플레이가 모두 있습니다. 빠져 있던 것은 “지금 내 패가 얼마나 강한가”를 보여 주는 정보 장치(핸드 강도, 올인 승률)와 긴장감을 주는 연출(카드 쪼기, 이긴 카드 강조, 래빗 헌트)이었습니다. 1인용 연습 게임에서는 이 두 가지가 체감 품질을 가장 크게 끌어올립니다.

반대로 로비를 기능으로 채우는 방향은 피했습니다. Zynga의 2014년 개편과 WSOP는 “불필요한 기능·그래픽이 플레이를 가린다”는 반발을 샀습니다. 그래서 새 기능은 모두 설정에서 끌 수 있게 했습니다.

이번에 넣은 기능 (v1.5)

1. 핸드 강도 막대 WSOP

하단 상태줄의 “내 패” 옆에 예상 승률 막대와 %가 붙습니다. 남은 상대 수(최대 5명)를 기준으로 몬테카를로 260회를 돌려 계산하고, 스트리트가 바뀔 때만 다시 계산합니다. 약하면 빨강, 강하면 초록으로 색이 변합니다.

근거: WSOP의 하단 핸드 강도 바 — pokerfuse

2. BB 배수 프리셋과 올인 버튼 PokerStars · GG

아무도 레이즈하지 않은 프리플랍에서는 프리셋이 2.5BB · 3BB · 4BB로 바뀝니다. 먼저 콜한 사람이 있으면 1명당 1BB를 더합니다. 플랍부터는 ½ 팟 · ⅔ 팟 · 팟이고, 빨간 올인 버튼이 새로 생겼습니다. 올인 확인 창은 그대로 유지됩니다.

근거: PokerStars 프리셋, ClubGG Bet-Pot 버튼

3. 올인 승률 % 배지 GG · ClubGG

올인 후 보드를 끝까지 펼치는 동안 각 플레이어 아바타 위에 승률이 뜹니다. 카드가 한 장 깔릴 때마다 남은 카드로 500회 시뮬레이션해 다시 계산합니다. 앞선 사람은 금색, 이길 길이 없는 사람은 흐리게 표시합니다.

근거: GG EV 캐시아웃의 에퀴티 표시

4. 카드 쪼기(스퀴즈) GGPoker

설정에서 켜면 내 카드가 뒷면으로 옵니다. 카드를 위로 밀면 모서리가 들리며 기울어지고, 충분히 밀거나 한 번 누르면 공개됩니다. 공개 전에는 족보와 강도 막대도 숨겨집니다. 기본값은 꺼짐입니다.

근거: GG/WSOP 온타리오 카드 스퀴즈

5. 이긴 카드 강조 + 금빛 파티클

쇼다운에서 승부를 가른 5장은 위로 들리며 금색으로 빛나고, 나머지 카드는 어둡게 가라앉습니다. 이긴 사람 자리에서 금빛 조각과 별이 터지고, 내가 이기거나 큰 팟이면 더 크게 터집니다. 승자 글로우는 숨 쉬듯 맥박칩니다.

기법: 위닝 카드 들어 올리기, 나머지 어둡게, 캔버스 파티클 — 보고서 그래픽 기법 7번

6. 래빗 헌트

모두 폴드해서 보드가 다 깔리기 전에 끝난 핸드에서, 결과창에 래빗 헌트 버튼이 생깁니다. 누르면 “계속했다면 나왔을 카드”를 반투명 점선 카드로 보여 주고 딜러 노트에 남깁니다. 실제 덱 순서 그대로, 버닝 카드까지 반영합니다.

근거: PokerNow 래빗 헌트, ClubGG

7. BB 단위 표시 · 그래픽 다듬기

설정에서 켜면 스택과 베팅이 “31.5BB”처럼 빅블라인드 배수로 보입니다. 그 밖에 보드 카드가 뒤집힐 때 광택이 한 번 훑고 지나가고, 테이블 바깥에 비네트를 더했습니다. 테이블 메뉴와 설정 창은 반투명 블러 유리 패널로 바꿨고, 숫자는 폭이 고정된 숫자체로 흔들리지 않게 했습니다. 움직임 줄이기 설정을 켠 기기에서는 파티클과 반복 애니메이션이 꺼집니다.

근거: 4색 덱·BB 단위 표시, PokerStars 2025 그래픽 통일

다음 단계 후보 (아직 넣지 않음)

  1. 칩 EV 캐시아웃 — 올인 후 승률 60% 이상이면 “지금 받기” 모달. 이번에 만든 승률 계산을 그대로 씁니다.
  2. 스트래들 — UTG 자발적 2BB. 클럽 테이블 만들기 옵션으로.
  3. 프리셋 커스텀 — 설정에서 버튼 4개 값을 직접 지정(PokerStars 방식).
  4. 로비 봄팟 카운트다운 — 방 카드에 폭탄 아이콘과 “3핸드 후” 표시(PokerBros 방식).
  5. 우편함·일일 미션 — 상단 바 재화 옆. 출석·룰렛과 묶기.
  6. 시즌 테이블 테마 — 겨울·연말 펠트와 카드 뒷면.
  7. 보드 카드 스퀴즈 — 큰 팟 리버에서 한 장씩 쪼기(GG 방식).

새 캐릭터 5명 요청 상태

보내 주신 사진 5장은 실존 인물의 얼굴을 그대로 옮기지 않고, 의상·분위기·콘셉트만 살린 오리지널 캐릭터로 만들 계획입니다(실존 인물 초상권 보호). 2번 사진은 노출을 낮춰 스트리트 콘셉트로 갑니다.

무료 우선 규칙에 따라 무료 이미지 생성(Pollinations)을 열어 시험했지만, 무료 서버가 지금 응답하지 않고(503) 새 주소는 키를 요구해 이번에는 그리지 못했습니다. 무료 키를 등록하거나 Higgsfield 크레딧 사용을 허락해 주시면 바로 이어 갑니다.
