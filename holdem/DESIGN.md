# 살롱 포커 클럽 — 게임 구조 설계

## 참고 앱 분석: 탑 로드 (GAME SPARK PTE. LTD., Google Play 전략 장르)
스토어 설명 기준 핵심 루프:
1. 간편한 조작, 짧은 세션 — 좌우로 달리며 병사를 늘리는 한 손 플레이
2. 도시 점령 → 성주가 되어 칙령 선포, 기사 임명, 공신 칭호 하사
3. 영웅 모집 → 스킬 마스터로 부대 강화
4. 전설의 신수 그리핀 육성
5. 명성을 쌓아 유일한 국왕이 되는 장기 목표

## 우리 홀덤에 적용한 구조
| 탑 로드 요소 | 살롱 포커 클럽 적용 |
|---|---|
| 짧고 간편한 플레이 | 빠른 시작, AOF(올인 or 폴드), 4.6초 자동 다음 핸드 |
| 도시 점령 | 정복 지도 6개 도시. 도시 보스와 1:1 공성전(헤즈업 싯앤고)에서 이기면 점령 |
| 성주의 수입 | 점령한 도시에서 시간당 조공 칩이 쌓임(최대 8시간), '조공 걷기'로 수령 |
| 칙령 선포 | 도시마다 수확령(조공 +25%) · 훈련령(명성 +10%) · 축제령(승리 보너스 +5%) 중 선택 |
| 기사 임명 | 보유 영웅을 도시 기사로 임명하면 그 도시 조공 +15% |
| 영웅 모집 · 스킬 | 12 캐릭터 = 영웅. 보스는 점령 시 합류, 나머지는 칩으로 영입. 각자 고유 스킬 1개 |
| 부대 편성 | 내 캐릭터 스킬(상시) + 동료 영웅 1명 스킬 |
| 신수 그리핀 육성 | 황금 그리핀: 핸드/승리로 성장(알 → 새끼 → 성체), 레벨당 팟 승리 보너스 +1%(최대 10%) |
| 명성 · 칭호 · 국왕 | 명성 경험치와 레벨, 평민 → 견습 기사 → … → 대공, 6개 도시 전부 점령 시 '국왕' |
| 일일 목표 | 오늘의 미션 5종(핸드, 팟 획득, AOF, 싯앤고/공성전, 조공) |

## 화면 구조 (세로형)
하단 탭: 게임(포커홀덤 · 싯앤고 · AOF) / 왕국(프로필 · 조공 · 그리핀 · 정복 지도) / 영웅 / 미션 / 랭킹(클럽 랭킹 + 내 기록)

모든 칩은 현금 가치가 없는 게임용 가상 칩이다.
